# Sons da bandeja

Recortes do áudio do vídeo `20261115-1528-46.9209619.mp4`, enviado pelo usuário como referência para o efeito dos dados.

- `rolagem-1.wav` a `rolagem-4.wav`: quatro rolagens da referência, sem os intervalos de silêncio.
- `impacto.wav`: contato curto da terceira rolagem para os toques finais.

Preparação: mono, PCM de 16 bits a 24 kHz, remoção de graves abaixo de 90 Hz e agudos acima de 9,5 kHz, picos ajustados e fades curtos nas extremidades. A reprodução varia levemente o ritmo e respeita o mudo global. A síntese anterior permanece como alternativa se os arquivos não puderem ser carregados.
